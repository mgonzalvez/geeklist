📖 How to Create a Crafting Geeklist

Step-by-step instructions for guest hosts, updated May 2026 by @DrHenryArmitage.

  1. 1
    Create a new geeklist — Go to Geeklists → Create new on BoardGameGeek.
  2. 2
    Use the header template — Use the Header Generator above as a basis for the new geeklist header. Fill in all placeholders with the correct information.
  3. 3
    Replace all placeholders — The following items need your attention:
    • Month & Year — Insert the current month and year in lines 1, 3, and 10.
    • Theme — Insert this month's theme and any explanatory text in line 3.
    • PnP Playing Geeklist ID — Insert the geeklist ID in line 5.
    • Last month's entry count — Insert the number of entries in line 10.
    • Last month's crafting geeklist ID — Insert the geeklist ID in line 11.
  4. 4
    Publish the geeklist — Once done customizing the header, click "Continue to add items" (you don't need to add any items), then click "Publish".
  5. 5
    Copy the geeklist ID — Note the new geeklist ID from the URL or confirmation page.
  6. 6
    Announce on the subscription thread — Add a reply to the subscription thread (thread #482943) announcing that the current month's list is live.
  7. 7
    Notify last month's geeklist — Add a list comment to last month's crafting geeklist announcing the current month's list.
  8. 8
    Notify the PnP playing geeklist — Add a list comment to the current "PnP playing" geeklist announcing the current month's list.
